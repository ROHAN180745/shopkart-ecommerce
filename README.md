# 🛒 ShopKart

ShopKart is a simple e-commerce homepage built using HTML and CSS.  
This project was created to practice frontend web development and recreate the layout of a modern online shopping website.

## 📌 About the Project

ShopKart includes a navigation bar, search bar, product categories, hero section, shopping cart UI, and footer.

The main goal of this project is to practice creating a real-world website layout using HTML and CSS.

## ✨ Features

- 🏠 E-commerce homepage
- 🔍 Search bar UI
- 📍 Delivery location section
- 👤 Account and sign-in section
- 📦 Returns & Orders section
- 🛒 Shopping cart UI
- 🎯 Navigation panel
- 🖼️ Hero banner
- 🛍️ Product category cards
- ⬆️ Back to top section
- 📱 Responsive layout

## 🛠️ Technologies Used

- HTML
- CSS
- Font Awesome
